# 🪝 Grapple

A fast-paced, high-momentum grappling hook obby game for Roblox, inspired by **Spider-Man** and **Stickman Hook**.

---

## 🎮 Controls

| Action | Control | Description |
| :--- | :--- | :--- |
| **Grapple & Swing** | `Left Click` / `E` | Shoot grapple hook to attach and swing |
| **Jump Release / Launch** | `Space` | Detach rope with a forward momentum fling |
| **Pump / Reel In** | `W` | Accelerate along the swing arc and shorten the line |
| **Mobile** | `Touch Button` | On-screen button for tap-to-hook and release-to-fling |

---

## 🚀 Features

- **Physics-Driven Pendulum Swinging:** Smooth, zero-latency physical swinging using `RopeConstraint`.
- **Launch & Momentum Retention:** Fling yourself forward out of swings to chain jumps across obstacles.
- **Smart Target Aiming:** Raycast aiming with soft-lock cone assist for catching ledges and anchor points.
- **Multiplayer Visual Replication:** Dynamic glowing rope visuals replicated across clients.
